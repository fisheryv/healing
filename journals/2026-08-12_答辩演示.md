## 踩坑

- **cloudflared Quick Tunnel 长时间运行会僵死**：进程还在但 tunnel URL 不响应，日志空。答辩前必须重启拿新 URL，不能信任跑了很久的 tunnel 进程
- **vite preview 服务的是 build 产物**：pull 新代码后必须重新 `pnpm build` + 重启 preview，否则公网看到的还是旧 bundle。这点和 `vite dev`（HMR 自动热更新）不同
- **Bash 工具的 cd 不跨调用保留**：`cd src && pnpm build` 之后再单独跑 `pnpm preview` 会报 `NO_IMPORTER_MANIFEST_FOUND`，每次都要带 `cd`
