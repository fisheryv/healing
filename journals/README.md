# 工作日志 (journals)

存放个人或团队的工作日志、复盘、备忘。

## 命名约定

- 文件名：`YYYY-MM-DD_主题.md`，例如 `2026-08-10_合并队友更新.md`
- 单文件：当天一个主题就一个文件；多个主题用多个文件。
- 周报：`YYYY-Www_周报.md`，例如 `2026-W32_周报.md`。

## 内容建议

- 今日做了什么、改动了哪些文件
- 遇到的问题与解决思路
- 下一步计划
- 待确认 / TODO

## 不放什么

- 临时调试输出（用 `.log` 文件或 IDE console）
- 提交代码相关的产物（用 git）
- 长期文档（放进 `docs/`）
