## 关键决策

### 1. 放弃 Vercel，改用 build + preview + tunnel

- **Vercel 部署成功**但 `*.vercel.app` 在国内被 DNS 污染（解析到 Twitter 的 IP `199.16.158.104`，连接超时）
- **替代方案**：本地 `pnpm build` 生成生产构建 → `pnpm preview` 跑预览服务器（4173）→ cloudflared 暴露 4173 到公网
- **架构**：两个 tunnel——PB tunnel（8090）给 API，preview tunnel（4173）给前端。前端 build 时写死 `VITE_PB_URL` 指向 PB tunnel 域名
- **优势**：生产构建只有 3 个文件（HTML+JS+CSS，gzip 250KB），比 dev 模式几百个请求快十倍；走 Cloudflare CDN 不被墙

### 2. 用 flushSync 修复 navigate 时序问题

- **症状**：artwork 成功保存到 PB，但 `navigate('/gallery')` 后 Gallery 不显示新画作，刷新才出现
- **根因**：React 18 的 automatic batching 把 `setArtworks` 和 `navigate` batch 在一起，但路由切换先于 state 更新应用，Gallery mount 时读到旧 state
- **修复**：在 `addArtwork` 里用 `flushSync(() => setArtworks(...))` 强制 state 同步更新，确保 navigate 前 state 已更新
- **验证**：localhost dev 模式修复成功；手机 preview 模式因浏览器缓存旧 JS 一开始没生效，清缓存后修复

### 3. 诊断方法

排查 artwork 不显示时，在 `addArtwork` 加了诊断 log：
```js
console.log('[addArtwork] called', { hasPreviewUrl: !!art.previewUrl, previewUrlLen: art.previewUrl?.length })
console.log('[addArtwork] artworksApi.create result:', { ok: res.ok, error: res.error })
```
log 显示 `ok: true, hasArtwork: true` + `previewUrlLen: 2278750`（2.2MB dataURL），确认保存成功，问题在前端显示。最后用 `flushSync` 修复后移除诊断 log。

## 修掉的 Bug

### Bug 1：Vercel 在国内被 DNS 污染

- **症状**：`curl https://healing-pink.vercel.app/` 返回 HTTP 000，DNS 解析到 `199.16.158.104`（Twitter 的 IP）
- **根因**：GFW 对 `*.vercel.app` 域名 DNS 污染
- **修复**：放弃 Vercel，改用 Cloudflare Tunnel + 本地 preview

### Bug 2：artwork 保存成功但 Gallery 不显示

- **症状**：完成专注后 Gallery 没有新画作，Profile session 数没更新，但 PB 里有记录
- **排查过程**：
  1. 查 PB → 有新记录（保存成功）
  2. 加诊断 log → `ok: true, hasArtwork: true`（上传成功）
  3. 刷新 Gallery → 新画作出现（state 没及时更新）
  4. 定位：React 18 batching 导致 `setArtworks` + `navigate` 时序问题
- **修复**：`flushSync` 强制同步更新 state

### Bug 3：手机上修复不生效

- **症状**：localhost 修复了，但手机上 Gallery 还是不显示
- **根因**：手机浏览器缓存了旧 JS（没有 flushSync 的版本）
- **修复**：手机清除缓存 / 用无痕模式

### Bug 4：vite preview 拒绝 tunnel 域名访问

- **症状**：手机访问 preview tunnel 返回 403 `This host is not allowed`
- **根因**：Vite 6+ 默认只允许 localhost，tunnel 域名被拒
- **修复**：vite.config.js 的 `preview` 配置加 `allowedHosts: ['.trycloudflare.com']`

### Bug 5：合并冲突

- **症状**：`git stash pop` 后 `.gitignore` 冲突
- **根因**：队友更新了 .gitignore（加了更全面的规则），本地 stash 只加了 `.vercel`
- **修复**：保留队友的版本 + 加 `.vercel`
