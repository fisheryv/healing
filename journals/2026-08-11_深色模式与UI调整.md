## 关键决策

### 1. 深色模式：CSS 变量 + data-theme 属性

- `:root` 已有 10 个 CSS 变量（`--bg`/`--ink`/`--line` 等），所有页面通过 `var(--xxx)` 引用
- 只需在 `[data-theme="dark"]` 下重定义这些变量即可全局生效
- 新增 9 个语义变量（`--shell-bg`/`--nav-bg`/`--card-focus` 等）提取硬编码色
- `html` 加 `color-scheme: light dark` + 全局 `transition` 0.2s 平滑切换

### 2. 三档主题：light / dark / system

- `system` 模式通过 `matchMedia('(prefers-color-scheme: dark)')` 监听系统变化
- 偏好存 localStorage `healing_app_theme_v1`，默认 `system`
- `main.jsx` 在 React 渲染前同步设 `html data-theme`，防闪屏（FOUC）

### 3. 白字白背景 bug 修复

- **根因**：6 处按钮用 `background: var(--ink); color: #fff`。浅色模式下 `--ink` 是深色，白字可见；深色模式把 `--ink` 翻成浅色 `#e8e6e3`，白字落在浅底上看不见
- **修复**：`color: #fff` → `color: var(--bg)`。`--bg` 永远跟 `--ink` 反相（浅色模式白、深色模式深），保证对比度
- **涉及的 6 处**：`.btn` / `.code-btn:hover` / `.lang-btn.active` / `.action-btn-fill` / `.play-btn` / `.sheet .pill.checked`

### 4. 深色色值方案（深灰柔和风格）

| 变量 | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| `--bg` | `#ffffff` | `#1a1a1a` | 主背景 |
| `--ink` | `#111111` | `#e8e6e3` | 主文字（暖白略带纸感） |
| `--ink-soft` | `#555555` | `#a8a6a3` | 次级文字 |
| `--ink-muted` | `#9a9a9a` | `#6a6865` | 弱化文字 |
| `--line` | `#e5e5e3` | `#333333` | 分割线 |
| `--line-strong` | `#cfcfcd` | `#444444` | 强调边框 |

水墨画布相关（`.suminagashi-*` / `.focus-session`）保持不变，有自己的配色体系。

## 深色模式架构

```
main.jsx 防闪屏
  ↓ 同步读 localStorage 设 html data-theme
  ↓
store.jsx AppProvider
  ↓ theme state (light/dark/system)
  ↓ matchMedia listener (system 模式实时响应)
  ↓ changeTheme() → 写 localStorage + 设 html data-theme
  ↓
Profile.jsx 主题选择器
  ↓ setTheme()
  ↓
CSS [data-theme="dark"]
  ↓ 重定义全部变量
  ↓ 全局 transition 0.2s 平滑切换
```
