## 1. 概述

### 1.1 背景

注意力缺陷多动障碍（Attention-Deficit/Hyperactivity Disorder, ADHD）作为一种全球高发的神经发育障碍，其核心临床表型涉及持续性注意力不集中、冲动控制受损以及工作记忆的缺陷 。随着认知神经科学与计算声学的交叉发展，基于听觉刺激的非药物干预策略，尤其是功能性音乐疗法，被众多研究证实可以改善 ADHD 群体的专注力。

ADHD 群体在日常学习和工作中，极易受到来自手机通知、环境噪音和高刺激内容的干扰。现有的效率工具要么界面信息密度过高，要么仅靠"数字倒计时"制造压迫感，难以为这类人群建立持续的专注动力。

希音（Healing）希望为 ADHD 群体构建一个低刺激、高反馈的数字庇护所，通过专注音乐+基于水墨（Suminagashi）渲染引擎的动态抽象艺术，**将枯燥的专注过程具象化为一段美学与心灵的成长之旅**。用户设置好时长和音乐组合后，将手机屏幕朝下放置，App 便在"看不见"的状态下，根据音乐的节奏和频率特征实时绘制一幅独一无二的水墨图案。专注结束之前，用户完全不知道会画出什么；翻开手机的那一刻才能看到成品——这份"惊喜感"本身，就是驱动 ADHD 用户坚持完成专注的内驱力。

### 1.2 目标

- 为 ADHD 用户及高压力脑力工作者提供一个视觉极简、听觉沉浸的专注工具。
- 以程序化生成艺术代替数字倒计时，将专注过程转化为可被记录、欣赏和分享的创作体验。
- 通过"Focus Music + 白噪音 + 双耳节拍"的多轨混音，让用户自由构建属于自己的专注听觉环境。

### 1.3 视觉与规范 (Design Language)

产品的 UI/UX 必须遵循“极简主义”原则，摒弃传统效率工具的工业感与游戏应用的高刺激感。

| **元素**     | **规范要求**                                                 |
| ------------ | ------------------------------------------------------------ |
| **主色调**   | 白色或米白色为全局背景底色，配色采用低饱和度配色 (如马卡龙色系) 。 |
| **线条色彩** | 低饱和度的墨蓝、赭石或深空灰，避免纯黑。                     |
| **排版字体** | 全局采用优雅的衬线字体 (Serif fonts)，营造沉静的禅意与文学氛围。 |
| **界面元素** | 极简无边框设计，无高光阴影，按钮与滑动条采用细线勾勒。       |

### 1.3 功能模块范围

| 大模块 | 子模块 | 功能点描述 |
|---|---|---|
| 用户账户 | 注册 / 登录 | 手机号、邮箱注册；手机号 / 邮箱 / Google / Apple ID / 微信登录 |
| 首页 | Home | 今日专注入口、人工精选推荐、我的收藏快捷访问、Blog 文章预览 |
| 专注模式 | Focus Session | 时长与音乐组合配置、屏幕朝下画布绘制、防分心机制、完成奖励（文学摘录 + 画作归档）、中途放弃残卷 |
| 曲库 | Library | 官方曲库（服务端获取）、我创建的混音方案、我的收藏 |
| 调音台 | Mixer | 主音乐 + 白噪音 + 双耳节拍三轨独立混音，实时预览，保存命名 |
| 画廊 | Gallery | 专注画作列表（含残卷）、作品详情、社交分享 |
| 我的 | Profile | 个人资料、专注热力图、统计数据、App 设置 |

App 底部常驻导航栏，从左到右五个 Tab 依次为：**首页（Home）、曲库（Library）、调音台（Mixer）、画廊（Gallery）、我的（My）**，当前选中 Tab 高亮显示。

### 1.4 名词与缩略语

| 术语 | 说明 |
|---|---|
| ADHD | 注意力缺陷多动障碍（Attention Deficit Hyperactivity Disorder） |
| Focus Music | 专为专注场景设计的功能性背景音乐，旋律简洁、无歌词、节奏稳定 |
| 双耳节拍（Binaural Beats） | 左右耳分别接收频率略有差异的两个纯音，大脑合成感知到一个"拍频"；**必须佩戴耳机方可生效**，外放无效 |
| 白噪音 | 各频率能量均匀的宽频噪音，用于掩蔽环境杂音 |
| 粉噪音 | 低频能量较强、比白噪音更柔和的噪音 |
| 褐噪音（布朗噪音） | 低频最突出、音色最深沉的噪音，类似远处雷声或急流声 |
| 氛围音 | 叠加在背景噪音之上的细节音效，如鸟鸣、翻书声、脚步声，用于增加空间层次感 |
| 混音方案 | 用户在调音台中配置并保存的音乐组合（主音乐 + 白噪音层 + 双耳节拍及各自音量设置） |
| 专注画作 | 专注过程中由水墨（Suminagashi）渲染引擎实时绘制的程序化抽象艺术图案 |
| 残卷 | 专注中途被打断、未完成的画作；以半透明 / 模糊状态归档，角落标注中断原因 |
| 热力图 | 类 GitHub Contributions 的日历方格图，颜色深浅反映当天的专注完成次数 |

## 2. 用户账户体系

### 2.1 业务流程

App 首次安装启动后直接进入注册 / 登录页，不设跳过选项。登录成功后跳转首页，登录状态长期有效（Token 机制），仅在主动退出登录或账号被封禁时失效。

未登录用户的功能限制如下：

| 功能 | 未登录可用？ | 触碰时的处理 |
|---|---|---|
| 浏览首页 / Blog | 是 | — |
| 浏览曲库官方 Tab | 是 | — |
| 开始专注 | 否 | 弹出提示框"登录后即可开始专注"，含【去登录】按钮 |
| 使用调音台 | 否 | 同上 |
| 查看画廊 | 否 | 同上 |
| 进入我的页面 | 否 | 直接跳转登录页 |

### 2.2 注册页

注册页顶部有两个 Tab：**手机号**和**邮箱**，默认选中手机号。

**手机号注册**

页面从上到下依次放置：国家区号选择器（默认 +86，点击展开常用区号列表，支持搜索）、手机号输入框、验证码输入框（右侧【发送验证码】按钮，点击后倒计时 60 秒，期间不可重复点击）、密码输入框、确认密码输入框，底部是【注册】按钮。

a. 手机号：必填，需符合所选区号对应的号码格式；格式不符时在输入框下方红色提示"请输入有效的手机号"。  
b. 验证码：必填，6 位数字，60 秒内有效，超时可重新发送。  
c. 密码：必填，8–20 位，需同时包含字母和数字；输入框右侧有明文 / 密文切换图标。  
d. 确认密码：必填，与密码不一致时提交校验提示"两次输入的密码不一致"。  
e. 点击【注册】后，完成本地格式校验，通过后调用注册接口；返回成功则自动登录，跳转昵称设置页（见 2.4 节）；若手机号已注册，提示"该手机号已注册"并提供文字链跳转登录页。

**邮箱注册**

字段与手机号注册基本一致，区别在于：邮箱格式需含 @ 及合法域名；验证码发送至填写的邮箱，有效期 10 分钟。其余字段和提交逻辑相同。

### 2.3 登录页

登录页顶部有两个 Tab：**手机号**和**邮箱**，切换后输入框内容清空。两种方式均支持"密码登录"和"验证码登录"互切，通过 Tab 下方的文字链"切换为验证码登录 / 切换为密码登录"操作。

**密码登录**

a. 输入账号（手机号或邮箱）和密码，点击【登录】。  
b. 密码连续错误 5 次，账号临时锁定 30 分钟，锁定期间显示"账号已锁定，请 X 分钟后再试"。  
c. 页面下方有【忘记密码？】文字链：点击后依次输入账号 → 获取验证码验证身份 → 设置新密码 → 完成，重置后自动登录进入首页。

**验证码登录**

输入账号后点击【发送验证码】，规则同注册页；验证码正确后直接登录。

**第三方登录**

密码 / 验证码登录区域下方用分割线隔开，依次排列 Google、Apple ID、微信三个登录按钮（图标 + 平台名称文字）。

- **Google / Apple ID**：调起系统级授权页，授权成功后返回 App；首次授权则系统自动创建账号并跳转昵称设置页；已有绑定记录则直接进入首页。  
- **微信**：设备未安装微信时按钮置灰，下方显示"请先安装微信客户端"；已安装时唤起微信授权，流程同上。

### 2.4 昵称设置页（首次登录）

注册或首次第三方登录成功后，展示一次昵称设置页。页面包含：头像占位圆（点击可从相册上传，非必须）、昵称输入框（最长 20 字，非必填）、【完成】按钮和【跳过】文字链。

跳过或点击完成后进入首页。跳过时昵称默认为"用户" + 账号后 4 位（如"用户8888"）。

## 3. 首页（Home）

### 3.1 页面整体结构

首页为纵向滚动布局，顶部固定显示问候语，内容区从上到下依次排列：

1. 今日专注入口卡片  
2. Mix Space 入口卡片（快捷进入调音台）  
3. 推荐板块（横向滑动卡片列表）  
4. 我的收藏板块（有收藏时展示，无收藏时整块隐藏）  
5. Blog 板块  

**顶部问候语**

左上方小字：`Welcome Back, {昵称}`；未设置昵称显示 `Welcome Back`。紧接其下方展示大号加粗标题，分两行：

```
How are you feeling
today?
```

此标题作为页面视觉重心，字号明显大于其他正文内容。

### 3.2 今日专注入口卡片

横向卡片铺满内容区宽度。卡片左侧为文字区，右侧为固定的品牌配图（抽象线条插图）。

文字区内容：
- 正文一行："开启今日的专注之旅"  
- 下方放置主色调的【开始】按钮  

点击【开始】按钮，跳转至**专注配置页**（详见第 4.2 节）。

### 3.3 Mix Space 入口卡片

紧接今日专注入口卡片下方，放置一张"Mix Space"入口卡片，作为调音台的快捷入口。卡片以极简风格呈现"Mix Space"标题与简短引导文案，点击卡片跳转至调音台页面（详见第 6 章），便于用户在不进入底部导航的情况下快速调整混音方案。

### 3.4 推荐板块

板块标题"推荐"，右侧"更多 ›"文字链，点击跳转至全部推荐列表页（以竖向列表展示全部推荐歌曲，可进行收藏操作）。

内容区为**横向滑动的方形卡片列表**，卡片间有统一间距，左右两侧留出边距露出相邻卡片，暗示可滑动。每张卡片展示：
- 歌曲封面图（正方形，占卡片主体面积）  
- 歌曲名称（1 行，超出省略）  
- 副标签（风格或场景标注，如"Lo-fi · 专注"、"Classical · 阅读"）  

点击任意卡片，进入该歌曲的详情页（可播放预览、收藏、选入调音台）。

推荐内容由运营人员在管理后台手动配置，前端按接口返回顺序展示，不做本地排序或过滤。

### 3.5 我的收藏板块

**有收藏记录时**：板块标题"我的收藏"，右侧"更多 ›"文字链（跳转至曲库页并定位到"我的收藏" Tab）。内容区为**纵向歌曲列表**，首页最多展示 5 条，每条显示歌曲封面缩略图、歌曲名称（1 行）、风格标签和时长。点击任意条目进入歌曲详情页。

**无收藏记录时**：整个板块不渲染、不占位，Blog 板块直接上移，页面无空白区域。

### 3.6 Blog 板块

板块标题"Blog"，右侧"更多 ›"文字链（跳转至全部文章列表页，显示所有文章，按发布时间倒序排列）。

首页展示最新 3 篇文章，以纵向列表排列，每条显示：
- 文章标题（最多 2 行，超出省略）  
- 发布日期  

点击任意文章，跳转文章详情页，展示完整富文本内容（支持图片、段落样式）。

Blog 内容由运营人员在管理后台维护，不开放用户投稿。首页不设"暂无文章"空状态，运营侧应保证至少存在一篇已发布文章。

## 4. 专注模式（Focus Session）

### 4.1 业务流程总览

```
首页 / 调音台
  └── 点击【开始】→ 专注配置页
          └── 点击【开始专注】→ 3 秒倒计时过渡
                  └── 专注进行中（手机朝下绘画）
                          ├── 计时结束 → 完成奖励页 → 手动关闭 → 保存至画廊
                          └── 主动放弃 → 确认弹框 → 保存残卷 → 跳转画廊
```

中断分支：专注进行中 → 拿起手机或切换 App → 15 秒宽限倒计时
- 15 秒内放回 → 线条恢复，专注继续
- 超过 15 秒 → 线条保持半透明状态，专注继续但画质受损

### 4.2 专注配置页

用户从首页点击【开始】或从调音台点击【开始专注】后进入此页。页面分上下两个配置区域，底部是【开始专注】主按钮。

**专注时长**

以滚轮（Drum Roll Picker）形式展示可选时长，步进 5 分钟，可选范围：10 / 15 / 20 / 25 / 30 / 35 / 40 / 45 / 50 / 55 / 60 分钟，默认选中 25 分钟。选中的时长以大字体居中显示，上下相邻选项以较小字体显示并逐渐透明，形成滚筒纵深感。

**音乐组合**

显示当前将要使用的混音方案名称及简要摘要（例如："Lo-fi Rain — 雨声 + Alpha 波"）。点击该区域弹出选择面板：

a. 列出用户已保存的全部混音方案（方案名 + 成分摘要），点击直接选用。
b. 列表底部有"去调音台调整"入口，跳转调音台并在返回时自动带回最新配置。
c. 若用户从调音台点击【开始专注】进入，此处自动显示调音台当前配置（即使尚未保存为方案）。
d. 若用户完全没有保存过方案且非从调音台进入，显示提示"还没有音乐方案，先去调音台创建一个吧"并提供跳转入口。

**开始前提示**

如果所选混音方案包含双耳节拍，在【开始专注】按钮上方显示一行灰色小字："☞ Best experienced with headphones"。点击【开始专注】后，进行 3 秒倒数动画（数字 3 → 2 → 1 → 呼吸光晕展开），过渡到专注画布页。

### 4.3 专注进行中

**界面布局**

画布全屏展示，是页面的绝对主体。UI 元素仅保留两处：右上角一个极小的【放弃】文字按钮（低对比度，不抢眼），以及屏幕最底部一行小字"Best with Headphones"（仅在选用了双耳节拍时显示）。全程无数字倒计时，无进度条，绘制曲线的进展本身即是时间的视觉呈现。

**专注画作生成逻辑**

专注画作采用**水墨（Suminagashi）渲染引擎**实时生成，灵感来自日本墨流工艺。系统在二维流体场中模拟墨滴在水面的扩散、对流与相互渗透，画笔沿流场游走时持续将墨色注入流体，形成富有东方禅意、每一次都独一无二的抽象水墨图案。该方案取代了早期设计中基于数学参数方程（Lissajous / Rhodonea / Hypotrochoid / Logarithmic Spiral / Butterfly）的曲线绘制——数学曲线虽具秩序感但形态偏单调，且与"专注森林"等同类应用的视觉效果存在相似性，难以体现希音独有的美学气质；水墨的有机流变与不可预测性更契合"看不见的专注旅程"所追求的惊喜感。

专注开始时，系统完成以下初始化：

a. 初始化水墨引擎实例（Suminagashi），构建底层流体场（速度场 + 密度场）。
b. 在画布上依次滴入若干初始墨滴作为构图起点，墨色取自预设的墨色调色板（含墨黑 sumi、靛蓝 ai、朱砂 shu 等低饱和度色相），每个墨滴带有独立的位置、半径与浓度参数。
c. 创建一支虚拟"画笔"（brush），赋予初始位置、行进方向、色相相位等状态；画笔将在流场中持续游走并向流体注入新墨色。
d. 根据专注时长估算画笔的推进速度基准，使画作在计时结束时形成视觉上饱满的构图。

绘制过程中，主音乐轨道的实时音频分析结果作为微扰持续驱动画笔行为与流体演化：

- **振幅 → 画笔速度 / 墨色浓度**：实时计算主音乐的音量包络（RMS），经平滑处理后线性映射为画笔的行进速度与每帧注入墨色的浓度（strength）。音乐越强，画笔游走越快、墨色越浓；音乐转弱时画笔放缓、墨色变淡，形成"呼吸感"。
- **频谱质心 → 画笔方向 / 色相推进**：提取主音乐的瞬时频谱质心（Spectral Centroid），将其变化映射为画笔行进方向的轻微扰动（高频偏移多、低频偏移少），同时驱动色相相位的推进，使墨色在调色板中缓慢渐变，增加有机感。
- **频谱通量（节拍）→ 溅墨事件**：检测主音乐的频谱通量（Spectral Flux）突变作为节拍信号，每个拍点在画笔当前位置附近随机溅入一团新墨滴，形成节奏感的视觉呼应。溅墨事件设有冷却时间，避免密集拍点下墨色过度堆积。若同时选用了双耳节拍，节拍信号与固定拍频值共同参与触发判定。

视觉风格：画布背景为深色（接近纯黑），墨色为低饱和度的柔和色相，墨迹边缘随流体扩散呈现自然晕染，画笔当前点表现为一个小而明亮的发光圆点，身后轨迹与溅墨逐渐融入流场，营造墨水在水面游走、渗透的质感。

**屏幕朝下检测**

App 通过加速度计持续读取设备姿态，判断手机是否处于屏幕朝下状态。

- **"强制屏幕朝下"设置为开（默认）**：只有手机屏幕朝下时绘制处于激活状态；手机翻转或倾斜超过阈值时立即触发防分心机制（见下）。App 申请保持 CPU 活跃与后台音频播放权限，无论屏幕是否熄灭，绘制计算与音频均不中断。
- **"强制屏幕朝下"设置为关**：绘制不受手机姿态影响，全程持续进行；用户可正面观看画作实时生成；防分心机制同步停用；切换到其他 App 时后台音频持续播放，但绘制暂停，返回后继续。

**防分心机制**（仅"强制屏幕朝下"开启时有效）

手机被拿起或 App 切到后台时，触发以下时序：

1. 线条描绘**立即停止**，当前绘制点消失。
2. 已绘制的线条开始**逐渐褪色变模糊**，15 秒内缓慢过渡到半透明。
3. 画布中央浮现倒计时提示，随时间流逝透明度升高，例如："放下手机 — 12s"。
4. **15 秒内**手机重新朝下（或 App 切回前台）：褪色动画反向恢复，线条回到原清晰度，描绘从停止点继续，此次中断不记录。
5. **超过 15 秒**仍未放回：已褪色部分维持半透明状态不再恢复。此后即使手机放回，线条可以继续描绘新的部分，但此前褪色段落无法清晰化。画作完整度受损，但计时器仍正常运行，专注可继续完成。
6. 无论何时，用户均可点击右上角的【放弃专注】主动结束（见 4.5 节）。

### 4.4 专注完成（画作奖励页）

计时器归零时，触发以下完成序列：

1. 主音乐与噪音**缓慢淡出**（约 3 秒降至静音）。
2. 设备产生短促**双震动**提示 + 一声轻柔的完成提示音（以震动为主，不受静音开关影响）。
3. 画布上最后的绘制点平滑消失，画作**永久定格**。
4. 画布出现约 2 秒的**呼吸光晕**动画（一圈柔光向外扩散再收缩），标志创作完成。
5. 屏幕下方三分之一区域以半透明深色遮罩为底，**文学摘录以呼吸动画缓缓上浮**：
   - 上方：一段英文文学摘录或诗句（不超过 5 行，字体克制，留白充裕）
   - 下方：一行中文赏析（1–2 句，偏向感受性描述）
   - 内容由后端接口随机返回，接口侧维护去重逻辑，同一用户短期内不重复
6. 用户阅读后，**点击屏幕任意位置**或右上角的"→ 保存画作"按钮关闭奖励页。

关闭后，画作图像与配套文学摘录一并写入本地画廊，界面自动跳转至画廊页并定位至刚保存的画作。

### 4.5 中途放弃

专注进行中，点击右上角的【放弃专注】按钮，弹出确认框：

> **确认放弃此次专注？**
> 已绘制的图案将以「残卷」的形式保存到画廊。

- 点击【继续专注】：关闭弹框，音频恢复播放，若手机朝下则绘制继续。
- 点击【放弃】：
  a. 音频立即停止。
  b. 当前画布状态以**半透明风格**（整体降低不透明度至约 40%）保存为残卷。
  c. 画作右下角添加灰色标注，格式为："残卷 · 中断于 {已专注时长}"，并标注中断原因（主动放弃 / 长时间未放下手机）。
  d. 残卷写入本地画廊，无文学摘录奖励。
  e. 界面跳转至画廊页，该残卷默认排在列表首位。

## 5. 曲库（Library）

### 5.1 页面结构

曲库页顶部固定三个 Tab：**官方** / **我创建的** / **我的收藏**，默认展示官方 Tab。Tab 切换时页面内容滑动过渡，各 Tab 内容独立滚动。

### 5.2 官方 Tab

展示从服务端拉取的官方音乐列表，支持下拉刷新。内容区顶部有搜索框，可按歌曲名称和风格标签进行模糊搜索。

每条歌曲显示：左侧正方形封面缩略图、歌曲名称（加粗，1 行）、风格标签和时长（次级字色），右侧心形收藏图标（点击切换收藏状态，已收藏时图标填充，未收藏时为描边）。

点击歌曲条目，进入歌曲详情页（见 5.5 节）。

### 5.3 我创建的 Tab

展示用户在调音台中保存的全部混音方案。

**有方案时**：每条方案显示方案名称（加粗）、成分摘要（例如："Lo-fi Study · 雨声 · Alpha 波"）和保存日期。点击条目跳转至调音台页，并自动将该方案加载到三个轨道中。向左滑动条目，出现红色【删除】按钮；点击后弹出确认"确认删除该方案？删除后无法恢复"，确认则从列表移除。

**无方案时**：显示空状态插图 + 提示文字"还没有创建过混音方案" + 【去调音台创建】按钮，点击跳转调音台页。

### 5.4 我的收藏 Tab

展示用户收藏的歌曲列表，格式与官方 Tab 一致。向左滑动条目，出现【取消收藏】按钮，点击后从列表移除（同步更新官方 Tab 中对应歌曲的收藏图标状态）。

**无收藏时**：显示空状态 + 提示"还没有收藏的歌曲" + 【去发现】按钮，点击切换到官方 Tab。

### 5.5 歌曲详情页

页面顶部展示歌曲封面大图（铺满屏幕上半部分，带轻微模糊背景延伸效果）。封面下方依次展示：歌曲名称（大号标题）、风格 / 分类标签、时长、简介文字（如有，来自接口返回）。

页面操作区有两个主要按钮：

a. **▶ 试听**：点击播放 30 秒预览片段，循环播放；再次点击停止；离开详情页时自动停止。
b. **加入调音台 →**：点击跳转调音台页，将该歌曲预置为主音乐轨道（不影响其他轨道现有配置）。

右上角有收藏图标，与列表页收藏图标状态实时联动。

## 6. 调音台（Mixer）

### 6.1 页面结构

调音台页面从上到下排列三个轨道卡片（带圆角，各自独立）。页面底部固定两个按钮：左侧【保存方案】（次级样式），右侧【开始专注】（主色调主按钮）。

### 6.2 主音乐轨道

轨道卡片左侧有音乐音符图标和"主音乐"标签。

**未选择时**：中间区域显示"点击选择主音乐"灰色提示文字。点击卡片任意区域，弹出音乐选择底部面板，内容与曲库官方 Tab 一致，含搜索框。点击歌曲完成选择，面板关闭，轨道卡片更新为选中歌曲的封面缩略图和名称。

**已选择时**：显示歌曲封面小图 + 名称 + 风格标签，点击可重新选择；长按封面可试听 30 秒预览。卡片右侧为**音量滑块**，范围 0–100%，拖动时实时生效。

### 6.3 白噪音轨道

轨道卡片左侧有波浪图标和"白噪音"标签。点击卡片，弹出噪音选择底部面板，面板内分为两个区域：

**背景噪音（单选，共 11 个选项）**

- 纯噪音组（3 个）：白噪音 / 粉噪音 / 褐噪音，每项附一句特性说明（如"褐噪音 — 低沉如深流，掩蔽效果强"）
- 环境音组（8 个）：雨声 / 海浪 / 风声 / 森林 / 溪流 / 咖啡厅 / 篝火 / 雷声，每项配小图标

两组共 11 个选项单选，已选项显示勾选标记；再次点击已选项则取消选择（清空背景噪音）。

**氛围音（多选，最多 2 个）**

区域顶部显示"已选 X / 2"计数。共 12 个选项：鸟鸣 / 翻书声 / 键盘声 / 脚步声 / 咖啡研磨 / 纸张翻动 / 风铃 / 猫咪 / 写字声 / 火焰爆裂 / 蝉鸣 / 蟋蟀。选满 2 个后其余选项置灰；点击已选项取消后，其余选项恢复可点。

面板底部【完成】按钮关闭面板。面板关闭后，轨道卡片内展示已选背景噪音（含独立音量滑块）以及各氛围音（含独立音量滑块和 × 取消按钮），所有音量调整实时生效。

### 6.4 双耳节拍轨道

轨道卡片左侧有耳机图标和"双耳节拍"标签。点击卡片，弹出选择底部面板，展示 4 个频段选项：

| 频段 | 频率范围 | 一句话描述 |
|---|---|---|
| Delta 波 | 0.5–4 Hz | 深度慢波，适合深度放松与冥想入定 |
| Theta 波 | 4–8 Hz | 梦境边界，适合冥想与创意发散 |
| Alpha 波 | 8–13 Hz | 清醒放松，适合轻松专注与阅读学习 |
| Beta 波 | 13–30 Hz | 活跃思维，适合主动思考与高效学习 |

面板底部有"暂不使用"选项，点击清空当前已选频段。选中后面板关闭，轨道卡片显示频段名称和频率范围，右侧有独立音量滑块。选中任意双耳节拍后，轨道卡片下方显示灰色小字提示："☞ Best experienced with headphones"。

### 6.5 实时预览

调音台页面处于活跃状态时，三轨道音频**实时混合播放**：任何选项变更（选择新声音、调整音量）均即时生效。离开调音台页面时音频自动停止。

每个轨道卡片右上角有一个静音切换图标，点击临时静音该轨道（便于对比单独轨道效果），再次点击取消；静音状态仅影响预览，不写入保存的方案。

### 6.6 保存方案

点击底部【保存方案】按钮，弹出命名输入面板：

a. 方案名称输入框：必填，最长 20 个字，提交时自动过滤首尾空格。
b. 若名称与已有方案重复，提示"已存在同名方案，是否覆盖？"，提供【覆盖保存】和【重新命名】两个选项。
c. 保存成功后，页面顶部短暂出现 Toast"已保存到「我创建的」✓"，面板关闭，调音台状态不变。

写入本地存储的方案数据包含：方案名称、主音乐 ID、背景噪音类型及音量、氛围音列表及各自音量、双耳节拍频段及音量、保存时间。

### 6.7 开始专注（调音台直接入口）

点击底部【开始专注】按钮：

a. 若主音乐轨道**未选择**：Toast 提示"请先选择主音乐"，不跳转。
b. 若主音乐已选择，检查当前配置是否与某个已保存方案完全一致：
   - **一致**：直接跳转专注配置页，配置自动载入。
   - **有未保存更改**：弹出提示"当前配置尚未保存，是否先保存为方案？"，提供【保存后开始】（先走保存流程再跳转）、【直接开始】（携带临时配置跳转，不写入存储）、【取消】三个选项。

### 7.1 作品列表

画廊页以 **2 列网格**布局展示所有本地保存的画作（含完整作品和残卷）。页面顶部有一排筛选标签：**全部 / 已完成 / 残卷**，默认选中"全部"，点击标签切换显示范围，列表按创建时间倒序排列。

### 7.2 作品详情页

画作下方展示本次专注的配套文学摘录，排版与完成奖励页一致（英文原文 + 中文赏析），供用户重温。摘录下方为信息区，以轻描淡写的方式列出：

- 创作日期与时间
- 专注时长
- 所用渲染方式（如"水墨 Suminagashi"）
- 所用音乐组合名称（如"Lo-fi Rain · 雨声 · Alpha 波"）

**残卷的详情页**

画作以半透明效果展示，不附文学摘录。信息区展示：创作日期、已专注时长、中断原因（主动放弃 / 长时间未放下手机）。

页面右上角有【分享】图标按钮（见 7.3 节）。

### 7.3 分享功能

点击详情页右上角的【分享】按钮，弹出分享选项面板：

a. **仅分享画作**：导出画作图片（不含文学摘录），底部附带"希音 Healing"品牌水印（小字，低调）。
b. **分享画作 + 摘录**（仅完整作品可用）：将画作与文学摘录合并为一张竖向长图后导出，排版参考奖励页视觉。

选择导出样式后，调起系统原生分享面板（iOS Share Sheet / Android Sharesheet），由用户选择目标应用（微信、微博、相册保存等）。

残卷的分享选项仅保留"仅分享画作"，且导出图片保持半透明样式，不添加摘录。

**专注设置**

a. 强制屏幕朝下：开关，默认开启。关闭后专注时无需将手机朝下，防分心机制同步禁用（详见 4.3 节）。
b. 专注时勿扰：开关，默认关闭。开启后，App 引导用户跳转到系统设置手动启用勿扰模式，并在专注结束时提示用户自行关闭；App 本身不强制调起系统勿扰权限，以避免审核风险。

**账号与安全**

a. 修改昵称：跳转编辑页，规则同注册时的昵称设置。
b. 修改头像：打开相册选择或拍照。
c. 修改密码：需先验证当前密码，再设置新密码（规则同注册）；第三方登录账号若未设置过密码，此处显示"设置密码"。
d. 已绑定账号：列出已绑定的第三方登录方式（Google / Apple ID / 微信），每项可点击绑定或解绑。解绑时若该方式是账号唯一登录方式，则提示"请先绑定另一种登录方式后再解绑"。
e. 注销账号：点击后显示注意事项说明（本地数据将清空，操作不可恢复），需用户手动输入"确认注销"后方可执行；注销成功后清除所有本地数据并退出至注册 / 登录页。

**通知**

a. 专注完成提醒：开关，控制专注结束时是否发出系统通知（适用于手机不在手边时的提醒）；首次开启时向系统申请通知权限。

**关于**

a. 当前版本号（仅展示，不可点击）。
b. 用户协议：跳转 Webview 展示协议页面。
c. 隐私政策：跳转 Webview 展示政策页面。
d. 意见反馈：跳转反馈表单页或打开系统邮件客户端（预填收件地址）。

**退出登录**

列表底部放置【退出登录】按钮（红色文字，次级样式），点击后弹出确认，确认后清除本地登录态并跳转至注册 / 登录页（本地画廊、方案等数据不随退出删除）。

### 10.2 音频质量规范

a. 所有循环播放的音频素材（白噪音、环境音、氛围音）必须经过**过零点剪辑**（zero-crossing edit），确保首尾连接时无"咔哒"声（click artifact）。
b. 音频格式：主音乐采用 AAC 或 MP3，码率不低于 128 kbps；噪音类音频 64 kbps 即可满足需求。
c. 专注模式下，App 通过申请 Audio Session Category（iOS）或 AudioFocus（Android）取得音频焦点，使外部来电铃声、消息提示音等降低音量或静默，提供沉浸式听觉体验。
d. 三轨音频混合播放时，任一轨道的音量均可独立调节，混合输出总音量不超过系统媒体音量上限，避免削波失真。

### 10.3 Flutter 双端适配要点

a. **最低支持版本**：iOS 14.0 及以上，Android 8.0（API Level 26）及以上。
b. **传感器**：使用 `sensors_plus` 包读取加速度计数据，面朝下判断阈值建议为 Z 轴加速度值 > 8 m/s²（重力方向向上，即屏幕朝下）；该阈值可在配置中微调以适配不同机型。
c. **后台音频**：使用 `audio_service` + `just_audio` 组合，在独立 isolate 中运行后台音频服务，确保锁屏和屏幕熄灭状态下音频不中断。
d. **画布渲染**：专注画布使用 Flutter `CustomPaint` + `Canvas` API 实现水墨（Suminagashi）渲染引擎的实时绘制。引擎内部维护二维流体场（速度场 + 密度场），每帧通过 `AnimationController` 推进流体演化与画笔游走，利用 `drawPath` / `drawCircle` 绘制墨迹与溅墨；建议将已稳定的墨迹缓存为 `Picture`，每帧仅重绘增量部分（画笔当前位置、新溅墨滴及其扩散区域），避免全量重绘带来的性能开销。
e. **音频实时分析**：振幅（RMS）和节拍检测通过 Native Channel 调用平台原生 API（iOS：AVAudioEngine tap；Android：AudioRecord + FFT），将分析结果以高频率回调传入 Flutter 层驱动画布微扰。
f. **防息屏**：使用 `wakelock_plus` 包在专注进行中保持屏幕常亮（即便屏幕朝下，CPU 和绘制进程依然活跃）；专注结束或用户退出时立即释放 WakeLock。
