# 希音 Healing

A Digital Sanctuary for ADHD Minds

希音，取自《老子》"大音希声"，是一款为 ADHD 群体构建一个低刺激、高反馈的数字庇护所。通过专注音乐+基于数学方程的动态抽象艺术，**将枯燥的专注过程具象化为一段美学与心灵的成长之旅**。

---

## 项目简介

希音（Healing）面向 ADHD 群体及高压力脑力工作者，解决"易分心、难专注"的核心痛点。用户设置好专注时长与音乐组合后，将手机屏幕朝下放置，App 便在"看不见"的状态下，根据音乐节奏与频率特征实时绘制一幅独一无二的抽象图案。专注结束时翻开手机才能看到成品——这份"惊喜感"本身，就是驱动 ADHD 用户坚持完成专注的内驱力。

- **听觉锚点**：Focus Music + 白噪音/氛围音 + 双耳节拍的多轨混音，隔绝外界干扰，建立内心秩序。
- **视觉奖励**：以程序化生成艺术代替充满压迫感的数字倒计时，将专注过程转化为可记录、欣赏与分享的创作。
- **低多巴胺反馈**：完成后通过英文文学摘录与克制的视觉留存，提供长效的心流满足感。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 用户账户 | 手机号 / 邮箱注册登录，支持 Google / Apple ID / 微信第三方登录，首次登录设置昵称与头像 |
| 首页 Home | 问候语、今日专注入口、人工精选推荐、我的收藏、Blog 文章预览 |
| 专注模式 Focus Session | 时长与混音方案配置、3 秒倒计时过渡、屏幕朝下绘制、防分心机制、完成奖励（文学摘录 + 画作归档）、中途放弃残卷 |
| 曲库 Library | 官方曲库（服务端获取）、我创建的混音方案、我的收藏 |
| 调音台 Mixer | 主音乐 + 白噪音/氛围音 + 双耳节拍三轨独立混音，实时预览，命名保存 |

| 我的 Profile | 个人资料、专注热力图（类 GitHub Contributions）、统计数据、应用设置 |

底部常驻导航栏五个 Tab：**首页 / 曲库 / 调音台 / 画廊 / 我的**。

## 专注画作生成逻辑

专注开始时，从五种参数方程中随机选取一种曲线类型，并在美学验证过的参数范围内生成初始参数，确保每次生成的曲线形态均有别于历史记录：

- **李萨如曲线**（Lissajous）：两个正弦频率的叠加，生成封闭或开放的交叉图案
- **玫瑰线**（Rhodonea）：极坐标下的花瓣状辐射图案
- **万花尺曲线**（Hypotrochoid）：滚动圆轨迹，类似万花尺绘图仪效果
- **黄金螺旋**（Logarithmic Spiral）：自相似的对数螺旋，向外舒展延伸
- **蝴蝶曲线**（Butterfly Curve）：基于超越函数的复杂对称图案

绘制过程中，主音乐轨道的实时音频分析结果作为"微扰"持续注入参数方程：

- **振幅 → 极径呼吸**：音量包络（RMS）映射为曲线整体缩放系数的微量波动，线条随音乐强弱缓慢"呼吸"。
- **频率 → 相位折皱**：瞬时主频（FFT）变化映射为相位偏移量的轻微扰动，让线条每圈轨迹产生细微错位与折皱。
- **节拍 → 时间步长**：检测到的节拍（BPM）在拍点处给 θ 推进速度叠加短暂加速量；若选用双耳节拍，其固定拍频也参与叠加。

## 防分心机制

通过加速度计持续读取设备姿态判断屏幕朝下状态（"强制屏幕朝下"默认开启）：

1. 手机被拿起或 App 切到后台时，线条描绘**立即停止**，已绘制部分开始**逐渐褪色变模糊**。
2. 画布中央浮现倒计时提示（如"放下手机 — 12s"）。
3. **15 秒内**放回：褪色动画反向恢复，描绘从停止点继续，此次中断不记录。
4. **超过 15 秒**：已褪色部分维持半透明不再恢复，后续可继续描绘新部分，但画作完整度受损，计时器正常运行。

## 完成奖励与残卷

- **完成奖励**：计时归零时音乐淡出、设备双震动提示，画作永久定格并伴随呼吸光晕动画；屏幕下方浮现英文文学摘录与中文赏析（后端去重，同一用户短期不重复）。点击保存后写入本地画廊。
- **中途放弃**：点击右上角【放弃专注】并确认后，画布以约 40% 不透明度保存为「残卷」，右下角标注"残卷 · 中断于 {已专注时长}"及中断原因，无文学摘录。

## 设计语言

| 元素 | 规范 |
| --- | --- |
| 主色调 | 白色或米白色为全局背景，低饱和度配色（如马卡龙色系） |
| 线条色彩 | 低饱和度的墨蓝、赭石或深空灰，避免纯黑 |
| 排版字体 | 全局采用优雅的衬线字体，营造沉静的禅意与文学氛围 |
| 界面元素 | 极简无边框设计，无高光阴影，按钮与滑动条采用细线勾勒 |

## 技术栈

Demo 实现位于 [`src/`](src/) 目录，基于以下技术栈：

- **React 18** + **Vite** + **React Router**（Hash 模式）
- **lucide-react** 图标库
- 设计风格：极简主义、黑白配色、衬线字体（Cormorant Garamond / Noto Serif SC）
- 全局状态：React Context（用户、收藏、混音方案、画作、设置）

## 启动方式

```bash
cd src
npm install
npm run dev
```

默认会在 `http://localhost:5173/` 启动。建议在浏览器中开启移动端调试视图（375 × 812 等）以获得最佳观感。

## Demo 演示要点

1. **登录页**：任意手机号 / 邮箱 + 密码即可登录（Demo 模式，无后端校验）。
2. **首页**：点击「Begin」进入专注配置；推荐、Blog 模块展示静态数据。
3. **调音台**：可选主音乐、白噪音 / 氛围音（最多 2 个）、双耳节拍频段，并保存为方案。
4. **专注模式**：
   - 3 秒倒计时过渡 → 画布开始用参数方程实时绘制曲线；
   - 为方便预览，Demo 将「1 分钟」压缩为「1 秒」，因此 25 min 的专注大约 25 秒结束；
   - 完成后展示文学摘录奖励页，点击可保存到画廊；
   - 右上角「Abandon」可中途放弃并以半透明残卷形式保存。
5. **画廊**：网格展示画作，残卷整体半透明并带「残卷」角标。
6. **我的**：包含热力图占位、统计数据、专注 / 账号 / 关于 设置组、退出登录。
