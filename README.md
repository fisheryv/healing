# 希音 Healing

A Digital Sanctuary for ADHD Minds

希音，取自《老子》"大音希声"，是一款为 ADHD 群体构建的低刺激、高反馈的数字庇护所。通过专注音乐 + 基于水墨（Suminagashi）渲染引擎的动态抽象艺术，**将枯燥的专注过程具象化为一段美学与心灵的成长之旅**。

---

## 项目简介

希音（Healing）面向 ADHD 群体及高压力脑力工作者，解决"易分心、难专注"的核心痛点。用户设置好专注时长与音乐组合后，将手机屏幕朝下放置，App 便在"看不见"的状态下，根据音乐节奏与频率特征实时绘制一幅独一无二的水墨图案。专注结束时翻开手机才能看到成品——这份"惊喜感"本身，就是驱动 ADHD 用户坚持完成专注的内驱力。

- **听觉锚点**：Focus Music + 白噪音/氛围音 + 双耳节拍的多轨混音，隔绝外界干扰，建立内心秩序。
- **视觉奖励**：以程序化生成艺术代替充满压迫感的数字倒计时，将专注过程转化为可记录、欣赏与分享的创作。
- **低多巴胺反馈**：完成后通过英文文学摘录与克制的视觉留存，提供长效的心流满足感。

| --- | --- |

## 专注画作生成逻辑

专注画作采用**水墨（Suminagashi）渲染引擎**实时生成，灵感来自日本墨流工艺。系统在二维流体场中模拟墨滴在水面的扩散、对流与相互渗透，画笔沿流场游走时持续将墨色注入流体，形成富有东方禅意、每一次都独一无二的抽象水墨图案。

专注开始时，系统完成以下初始化：

a. 初始化水墨引擎实例（Suminagashi），构建底层流体场（速度场 + 密度场）。
b. 在画布上依次滴入若干初始墨滴作为构图起点，墨色取自预设的墨色调色板（含墨黑 sumi、靛蓝 ai、朱砂 shu 等低饱和度色相）。
c. 创建一支虚拟"画笔"（brush），赋予初始位置、行进方向、色相相位等状态。
d. 根据专注时长估算画笔的推进速度基准，使画作在计时结束时形成视觉上饱满的构图。

绘制过程中，主音乐轨道的实时音频分析结果作为微扰持续驱动画笔行为与流体演化：

- **振幅 → 画笔速度 / 墨色浓度**：音量包络（RMS）映射为画笔行进速度与每帧注入墨色的浓度，形成"呼吸感"。
- **频谱质心 → 画笔方向 / 色相推进**：瞬时频谱质心变化映射为画笔行进方向的轻微扰动，同时驱动色相相位的推进。
- **频谱通量（节拍）→ 溅墨事件**：检测频谱通量突变作为节拍信号，每个拍点在画笔当前位置附近随机溅入新墨滴，形成节奏感的视觉呼应。

> 早期设计曾考虑基于数学参数方程（李萨如曲线、玫瑰线、万花尺曲线、黄金螺旋、蝴蝶曲线）生成抽象线条。经评估，数学曲线形态偏单调，且与同类应用的视觉效果存在相似性，故改用水墨渲染方案。

## 防分心机制

通过设备方向传感器持续读取设备姿态判断屏幕朝下状态（"强制屏幕朝下"默认开启）：

1. 手机被拿起或 App 切到后台时，线条描绘**立即停止**，已绘制部分开始**逐渐褪色变模糊**。
2. 画布中央浮现倒计时提示（如"放下手机 — 12s"）。
3. **15 秒内**放回：褪色动画反向恢复，描绘从停止点继续，此次中断不记录。
4. **超过 15 秒**：已褪色部分维持半透明不再恢复，后续可继续描绘新部分，但画作完整度受损，计时器正常运行。

## 完成奖励与残卷

- **完成奖励**：计时归零时音乐淡出、设备震动提示，画作永久定格并伴随呼吸光晕动画；屏幕下方浮现英文文学摘录与中文赏析。点击保存后写入本地画廊。
- **中途放弃**：点击右上角【放弃专注】并确认后，画布以约 40% 不透明度保存为「残卷」，右下角标注"残卷 · 中断于 {已专注时长}"及中断原因，无文学摘录。

## 账号与安全

- **注册**：支持邮箱 / 手机号注册，需设置昵称、密码（8–20 位，含字母和数字）、以及一个自定义安全问题和答案。
- **登录**：邮箱 / 手机号 + 密码登录，连续错误 5 次锁定 30 分钟。支持"记住我"。
- **忘记密码**：通过注册时设置的安全问题验证身份后重置密码，无需邮件/短信验证码。
- **第三方登录**：Google / Apple ID / 微信入口（当前为占位，暂未接入真实后端）。

> 当前版本为纯前端 Demo，所有账户数据存储在浏览器 localStorage 中，密码和安全问题答案均经过哈希处理。后续接入后端后可迁移至服务端。

## 设计语言

| 元素 | 规范 |
| --- | --- |
| 主色调 | 白色或米白色为全局背景，低饱和度配色（如马卡龙色系） |
| 线条色彩 | 低饱和度的墨蓝、赭石或深空灰，避免纯黑 |
| 排版字体 | 全局采用优雅的衬线字体，营造沉静的禅意与文学氛围 |
| 界面元素 | 极简无边框设计，无高光阴影，按钮与滑动条采用细线勾勒 |

## 技术栈

Demo 实现位于 [`src/`](src/) 目录，基于以下技术栈：

- **React 18** + **Vite** + **React Router v6**
- **Web Audio API**：音频合成与混音（纯噪音和双耳节拍实时合成，无需音频文件）
- **HTML5 Canvas 2D API**：水墨（Suminagashi）渲染引擎实时绘制
- **lucide-react** 图标库
- 设计风格：极简主义、低饱和度配色、衬线字体（Cormorant Garamond / Noto Serif SC）
- 全局状态：React Context + localStorage 持久化（用户、收藏、混音方案、画作、设置、账户库）
- 数据存储：浏览器 localStorage（无后端依赖）

## 启动方式

```bash
cd src
npm install
npm run dev
```

默认会在 `http://localhost:5173/` 启动。建议在浏览器中开启移动端调试视图（375 × 812 等）以获得最佳观感。

## Demo 演示要点

1. **注册 / 登录**：先用邮箱或手机号注册（需填写安全问题），注册成功后设置昵称即可进入首页。后续可用同一账号登录。
2. **首页**：点击「Begin」进入专注配置；推荐、Blog 模块展示静态数据。
3. **调音台**：可选主音乐、背景噪音 / 氛围音（最多 2 个）、双耳节拍频段，并保存为方案。
4. **专注模式**：
   - 3 秒倒计时过渡 → 画布开始用水墨引擎实时绘制；
   - 为方便预览，Demo 将「1 分钟」压缩为「1 秒」，因此 25 min 的专注大约 25 秒结束；
   - 完成后展示文学摘录奖励页，点击可保存到画廊；
   - 右上角「Abandon」可中途放弃并以半透明残卷形式保存。
5. **曲库**：官方 Tab 可搜索和收藏音乐；我的混音 Tab 支持左滑删除方案；收藏 Tab 支持左滑取消收藏。
6. **画廊**：网格展示画作，残卷整体半透明并带「残卷」角标。
7. **我的**：包含热力图占位、统计数据、专注 / 账号 / 关于设置组、退出登录。
